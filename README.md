# 婕妤 · 个人作品集

基于原生 HTML / CSS / JavaScript 构建的个人作品集单页网站，展示个人介绍、精选项目与联系方式。无需任何框架与第三方依赖。

## 功能特性

- **数据驱动渲染**：所有内容集中于 `js/data.js`（`PROFILE` 个人信息与 `PROJECTS` 项目列表），修改数据即可全站生效，项目编号、目录索引与排版自动更新
- **作品展示**：目录索引（点击跳转对应项目）+ 项目列表，支持三种排版模板（`variant: a/b/c`，不填自动轮换）
- **深浅色主题切换**：导航栏右侧切换按钮，`localStorage` 记住选择，首屏渲染前应用主题避免闪白
- **关于我**：个人导语、双栏正文、技能方向与教育背景
- **联系方式**：支持 mailto 与外链（自动新窗口打开）
- **交互细节**：滚动时导航状态变化、滚动淡入动画（IntersectionObserver）、移动端汉堡菜单
- **响应式布局**：兼容桌面端与移动端

## 技术栈

- HTML5（语义化标签 + 内联主题预加载脚本）
- CSS3（CSS 变量实现主题切换）
- 原生 JavaScript（ES6+，无任何依赖）

## 目录结构

```
lab04/
├── index.html          # 页面结构
├── css/style.css       # 样式（含深浅色主题变量）
├── js/data.js          # 内容源：个人信息与项目数据
├── js/main.js          # 渲染与交互逻辑
├── assets/images/      # 头像与项目配图
└── profile.md          # 真实资料（内容来源，更新后同步到 data.js）
```

## 运行方式

纯静态页面，无需构建。直接双击打开 `index.html`，或使用本地服务器：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后访问 `http://localhost:8000`。
